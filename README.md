## 👨‍💻 About Me

I'm an **AI & Computer Vision Engineer** focused on developing and deploying
real-time vision systems for practical industrial and surveillance applications.

My work covers the complete computer vision lifecycle:

**Dataset → Annotation → Training → Evaluation → Optimization → Testing → Deployment**

I work primarily with **YOLO-based object detection, image processing, OCR,
ANPR/LPR systems, real-time video analytics, and edge AI deployment**.

I enjoy solving practical problems where model accuracy depends not only on
training, but also on **camera positioning, image quality, preprocessing,
dataset quality, inference optimization, and deployment constraints**.

---

## 🚀 What I Work On

### 🧠 Computer Vision & Deep Learning

- Object detection and classification using **YOLOv8 / YOLO11**
- Transfer learning and progressive model training
- Dataset collection, cleaning, balancing and annotation
- Hyperparameter tuning and model optimization
- Precision, Recall, F1-score, mAP50 and mAP50-95 evaluation
- Hard-negative analysis and false-positive reduction
- Real-time video inference and testing

### 🚘 ANPR / LPR & OCR

- Automatic Number Plate Recognition pipelines
- Vehicle → number plate detection
- Plate cropping and region extraction
- Perspective correction and deskewing
- Image enhancement for difficult plate images
- OCR preprocessing and post-processing
- PaddleOCR / EasyOCR experimentation
- Multi-frame OCR voting
- Indian number plate validation and regex-based correction
- Blur, contrast and brightness quality analysis

### ⚙️ Edge AI & Deployment

- Real-time computer vision pipelines
- NVIDIA Jetson edge devices
- ONNX-based inference
- OpenCV image/video processing
- Performance and memory optimization
- CCTV / RTSP stream processing
- Camera positioning and angle analysis for better AI accuracy

## 🔬 Featured Work

### 🚘 ANPR / Number Plate Recognition

A computer vision pipeline for detecting vehicles, extracting number plates,
processing plate regions and performing OCR.

**Pipeline:**

```text
CCTV / Image
     ↓
Vehicle Detection
     ↓
Number Plate Detection
     ↓
Plate ROI Extraction
     ↓
Deskew / Perspective Correction
     ↓
Crop & Region Refinement
     ↓
Image Enhancement
     ↓
OCR
     ↓
Multi-frame Voting
     ↓
Regex / Plate Validation
     ↓
Final Number Plate
```

**Technologies:**

`YOLO11` `OpenCV` `PaddleOCR` `EasyOCR` `ONNX` `Python`
